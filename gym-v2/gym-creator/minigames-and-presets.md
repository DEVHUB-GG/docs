# Minigames & Presets

Two independent boxes on one page: a test bench at the top, and the preset editor underneath.

***

## <mark style="color:yellow;">**TEST MINIGAMES**</mark>

Try any minigame at any difficulty without walking to a machine.

{% stepper %}
{% step %}
### Pick a difficulty

The numbered buttons from **1** to **8** next to the **Difficulty** label. 1 is the easiest, 8 the hardest.
{% endstep %}

{% step %}
### Click **Test** on the minigame you want

The creator closes, the minigame runs exactly as it would during a rep, and a notification tells you whether you passed.
{% endstep %}

{% step %}
### The creator reopens

You land back on the same page. Change the difficulty and try again.
{% endstep %}
{% endstepper %}

{% hint style="success" %}
Do this before you assign anything. Two minutes here saves you from shipping a gym where every rep is a coin flip.
{% endhint %}

***

## <mark style="color:yellow;">**MINIGAME PRESETS**</mark>

A preset is a named, reusable minigame set. Instead of ticking four minigames and dragging eight sliders on every bench you place, you build the set once and apply it with a single click from any machine or any global model.

### Creating one

{% stepper %}
{% step %}
### Click **New Preset**
{% endstep %}

{% step %}
### Give it a name

For example `Bench Press (Medium)`. Up to 48 characters. A preset without a name cannot be saved.
{% endstep %}

{% step %}
### Tick the minigames it should contain

Each ticked minigame expands to show its difficulty range.
{% endstep %}

{% step %}
### Set each minigame's difficulty range

Two sliders, both on the 1 to 8 scale. The left one is the minimum, the right one is the maximum. The current range is shown as `4-5 / 8` above the sliders.

The range is a ramp inside a set: the player's first rep sits at the minimum and the last rep at the maximum. Set both to the same number for constant difficulty.
{% endstep %}

{% step %}
### Click **Save Preset**
{% endstep %}
{% endstepper %}

### Using one

Open the minigame panel on any machine (the blue **gamepad** button) or on any row of the Global Models page. Your presets are the blue chips next to **Apply preset:**. Clicking one **replaces** that machine's whole minigame list with the preset's.

### Editing and deleting

Every saved preset has **Edit** and **Delete** buttons. Editing a preset does **not** update machines you already applied it to. It is a template, not a link, so re-apply it where you want the change.

{% hint style="info" %}
The install ships a few presets built around the standard machines, so you have something to apply from the first minute.
{% endhint %}
